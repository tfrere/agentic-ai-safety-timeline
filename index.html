How events are added

An AI agent runs a daily watch. Events that meet these rules are added automatically.

  1. Primary sources firstLab reports, independent evaluations, official statements and research.
  2. Evidence before inclusionThe agent reads the source and checks that it supports the claim.
  3. One event, one entrySkip duplicates and unsupported claims. Use the event date, not the discovery date.
